GOOD TO KNOW

   
Which version of the game do I need?
Call of Duty 4 patched to 1.7.

   
Do I need to install the PeZBOT mod?
No. The first time you start a game with bots, Thorium copies it to your game's mods folder.

   
My bots are not showing up
Make sure the game started with +set fs_game "mods/PeZBOT" +exec pezbot.cfg, then open the console once the map has loaded and enter svr_pezbots with a number. See the Bot Games page.

   
The console will not open
In the game, open Options, then Game Options, and set Enable Console to Yes. Then press the tilde key (~).

   
Windows Firewall asks for permission
Allow Thorium and iw3mp.exe the first time you start a game.
